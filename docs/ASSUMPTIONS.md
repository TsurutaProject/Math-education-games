# 仮置きした仕様と理由

依頼文であいまいだった点を、次のように仮置きしています。チームで決まったら変更してください。

## ルール・判定

| # | 仮置きした内容 | 理由 |
| --- | --- | --- |
| 1 | 弾数はすべての問題で 3 発 | 例が 3 発で、B の補正も「残り3発=補正なし」が基準になっているため。バリエーション間で条件をそろえるため |
| 2 | 今の数がマイナスになっても止めない（「−5」と表示） | 撃てないようにすると「試行錯誤」を止めてしまうため。ただし問題は「マイナスを通らなくても全部の解き方ができる」ものだけを採用し、図鑑の「？」に小学生が見つけにくい解き方が混ざらないようにした |
| 3 | 目標を超えたら「あと〇」の代わりに「こえた 〇」と表示。弾切れ時は「おしい！ 〇 こえちゃった」 | 「あと −5」は小学生に読みにくいため |
| 4 | 的が全部なくなったら弾が残っていても弾切れと同じ扱い | 撃つものがないため。問題は必ず「的の数 > 弾数」なので通常は起きない |
| 5 | A で何もない所をタップしても弾は減らない | A は「必ず当たる」基準なので、外れの概念を持ち込まないため |
| 6 | 0 に ×2 しても何も変わらないので、その手は解き方の正規化キーから除く（例：0×2+10+20 は 10+20 と同じ解き方） | 「何も変えない1発」で図鑑の数が水増しされるのを防ぐため。撃った弾は減る |
| 7 | 正規化では引き算も足し算と同じまとまりとして並べ替える（20−5 と −5+20 は同じ） | 依頼文の「足し算・引き算が続く部分」をそのまま適用。結果として 5−5+20 のような「打ち消し合う」解き方も別の解き方として数える |
| 8 | 解き方の種類が多すぎる問題（7 種類以上）は採用しない。1 発で目標になる的がある問題も採用しない | 図鑑を埋めたくなる量に収めるため／1 発で終わると算数を考える余地がないため |
| 9 | ステージ2では ×2 を使う解き方が必ず1つ以上ある | ×2 がただの飾りにならないようにするため |
| 10 | 割り算 ÷ は正規化・計算では扱えるが、問題データには入れていない | ステージ2の指定が +、−、×2 のため |

## C（リスクとリターン）

| # | 仮置きした内容 | 理由 |
| --- | --- | --- |
| 11 | C は A/B と別の問題セット（`set: "risk"`）を使う | 依頼の例題（目標40）は、大きくて止まっている的（10以下）だけでは3発で届かず、「安全な道」の条件を満たせないため |
| 12 | C の1問目は例を元に +10 を1つ足し、目標を 30 にした（10+10+10 が安全な道、10+20 が近道） | 例題の雰囲気を残しつつ条件を満たすため |
| 13 | 的の大きさのルール：×2 と 20 以上は小（S）、15 は中（M）、10 以下と引き算は大（L）。小の中で ×2 といちばん大きい数が動く | 「数が大きい的・×2 は小さく、一部が動く」を機械的に決めるため |
| 14 | 「当てやすい的」＝大（L）で止まっている的。「安全な道」はこれだけで届く解き方 | 中（M）は止まっているがやや小さいので、安全側に寄せて除外した |
| 15 | C の問題には「当てにくい的を使って弾が余る近道」も必ず入れた | リスクを取る見返り（弾が余る＝外しても取り返せる）がないと、リスクとリターンの比較にならないため |
| 16 | C は既定で救済補正なし（設定「C にも補正を使う」でオン） | 依頼の「狙い方は B と同じ」は操作方法の意味と解釈。補正があると小さい的のリスクが薄まるため |
| 17 | C の景品はクリア時に倒れて「ゲット！」。景品は問題ごとに決まった絵文字 | 外部素材を使わないため。景品は図鑑画面にも表示 |
| 18 | C の手応え：命中時に画面の揺れ・一瞬止まる（ヒットストップ）・的がぐらついてから倒れる・数のカウントアップ・「コトン」の音。連射の間隔も長め（0.55 秒） | 「倒れる間」を見せるため |

## 操作・表示

| # | 仮置きした内容 | 理由 |
| --- | --- | --- |
| 19 | B/C でタッチ操作のときは、照準を指より少し上（約 90 単位）に出す。マウスはカーソル位置そのまま | 指で照準が隠れて狙えなくなるため |
| 20 | 照準の揺れは小さな8の字（リサジュー曲線）。揺れ幅は設定で変更可（既定 12） | 「少し揺れる」の程度が未定のため |
| 21 | B の補正は、当たり判定の半径 × (1 + 強さ × k)。k は残り3発以上 0、2発 0.35、1発 0.8。強さは 0〜2（既定 1） | 「中」「大」の具体値が未定のため。強さ 1 で 1.35 倍・1.8 倍 |
| 22 | いまの式（例：10 + 20 = 30）を画面に小さく表示。設定でオフにできる | 計算の流れが見えた方が試行錯誤しやすい一方、「算数が前に出すぎる」懸念の比較対象になるため切り替え可能にした |
| 23 | 図鑑はバリエーションごと・問題ごとに別（A で見つけた解き方は B の図鑑には出ない） | バリエーションを切り替えて遊び比べるとき、前の結果が混ざらないようにするため |
| 24 | 図鑑のカードの式は、最初に見つけたときの撃った順で表示 | 自分で見つけた感じを残すため（同一判定は正規化キーで行う） |
| 25 | クリア後の画面に「べつの解き方をさがす」と「つぎの問題へ」。全部見つけたら「つぎの問題へ」を強調。弾切れ画面にも「つぎの問題へ」を小さく置いた | 何度やっても届かない子が抜け出せるようにするため（罰はなし） |
| 26 | 最後の問題の次は、次のステージ（最後のステージの次はステージ1）に進む | 文化祭で続けて遊べるようにするため |
| 27 | ログは localStorage に保存して再読み込みでも残す（図鑑は消える） | 文化祭当日のデータ収集で誤って消えないようにするため |
| 28 | 文言は小学校高学年が読める漢字（目標・数・問題・解き方 など）を使い、それ以外はひらがな | 依頼の「小学生が読める言葉」に合わせて |

## 射撃タイプ：パチンコ（追加分）

| # | 仮置きした内容 | 理由 |
| --- | --- | --- |
| 29 | 射撃タイプの切り替えは B・C だけ。A はタップ式のまま | A は「必ず当たる」基準なので、狙う操作を持ち込まないため |
| 30 | パチンコは「フィールドのどこを押してもよい」。押した点から引っ張った向きの反対に飛ぶ（モンスト式） | 発射台を正確に押す必要がないほうがタブレットで遊びやすいため |
| 31 | 引っ張る長さは向きを決めるだけで、弾の速さは一定（設定で変更、既定 800。発射位置から棚まで約0.35秒） | 「強く引きすぎて外れる」より「どこを狙うか」に集中させるため。速さがあることで動く的は先読みが必要になる |
| 32 | 真上から左右 75 度までしか飛ばない。短く引いただけ（24 単位未満）は撃たず、弾も減らない | 下向きに撃ってしまう、うっかりタップで弾が減る、を防ぐため |
| 33 | 弾は最初に触れた的で止まる（1発で倒れる的は1つ） | 「1発 = 演算1つ」のルールを守るため。モンストのように何体も貫通・連続ヒットはしない |
| 34 | 左右の壁ではね返る（既定オン）。上の壁でははね返らず、上に抜けたら外れ | モンストらしさを残しつつ、弾がいつまでも飛び続けないようにするため |
| 35 | パチンコのときは的を **1段** に並べる | 2段だと手前の的が奥の的をふさぐ。実際に C の1問目では奥の +10 にまっすぐも壁はね返りでも届かず、「安全な道」が撃てなかった。1段ならどの的にもまっすぐ届くことをテストで保証した |
| 36 | 1段に詰めたため、C の動く的の移動幅は小さめ（となりの的と重ならない範囲） | 重なると当たり判定があいまいになるため。物足りなければ「移動の速さ」を上げる |
| 37 | ねらいのガイドは点線で、長さは既定 260（棚の手前あたりまで）。0 でガイドなし | 全部の道すじが見えると狙う緊張感がなくなるため。長さで難しさを調整できる |
| 38 | 照準の揺れはパチンコでは「飛ぶ向きのぶれ」（揺れ幅 12 で約 ±2.4 度） | B の「照準は少し揺れる」を同じ設定で再現するため |
| 39 | B の補正はパチンコでも同じ倍率で、的の当たり判定（半径）を広げる | コルク銃と条件をそろえて比べるため |
| 40 | 図鑑はコルク銃とパチンコで別（B と B-パチンコ） | 遊び比べで結果が混ざらないようにするため（#23 と同じ考え） |
| 41 | パチンコの発射台を置く場所をつくるため、フィールドを少し縦長にした（1000×560 → 1000×620。コルク銃でも同じ） | 引っ張ったゴムが画面からはみ出さないようにするため |
