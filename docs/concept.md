# コンセプト

## だれに・いつ

- 小学校高学年
- 11月の文化祭で、子どもに遊んでもらう

## 狙い

算数が苦手な子でも、

- **試行錯誤できる**（失敗してもすぐやり直せる、罰がない）
- **解き方が何通りもある**（正解が1つで、間違えたら終わり、という作りにしない）

という体験を通して、算数の入り口のハードルを下げる。

## すべてのゲームで大事にしたいこと

- 失敗に罰をつけない。「おしい！あと〇」のように前向きに伝え、すぐやり直せる
- 「詰んでいます」のような判定は出さない。届くかどうかは子どもが自分で考える
- 見つけた解き方を集められる（射的の「解き方ずかん」）。別の解き方を探したくなる
- 算数が前に出すぎて「勉強っぽい」と感じさせない
- 画面の言葉は小学生が読める言葉にする
- 個人情報は記録しない
