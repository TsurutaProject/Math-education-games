# 遊び比べチェックシート

1人で A → B → C の順に遊ぶと、慣れの影響で後のものが有利になります。人によって順番を入れ替えてください（例：A→B→C、B→C→A、C→A→B）。
1つのバリエーションにつき「ステージ1を3問」くらいが目安です。

## 遊ぶ前に

- [ ] 設定パネルで「ログを消去」した（または前のログをダウンロードした）
- [ ] 効果音をオン、音量を確認した
- [ ] 遊ぶ順番を記録した：＿＿＿＿＿＿

## バリエーションごとに（A / B / C それぞれ ○△× と一言）

| 観点 | A | B | C |
| --- | --- | --- | --- |
| 最初の10秒で「やってみたい」と思ったか | | | |
| 説明なしで遊び方がわかったか | | | |
| 射的らしいと感じたか（狙って当てる緊張感） | | | |
| 当てられなくて、算数を考える気持ちが消えなかったか | | | |
| 算数が前に出すぎて「勉強っぽい」と感じなかったか | | | |
| 外したり届かなかったりしても、すぐもう一回やりたくなったか | | | |
| クリア後に「べつの解き方」を探したくなったか | | | |
| 図鑑の「？」が気になったか | | | |
| 撃つ前に計算（あと〇を考える）をしていたか | | | |
| 1回の挑戦にかかった時間はちょうどよいか | | | |

## B について

- [ ] 照準の揺れは「緊張感」になっていたか、「イライラ」になっていたか（揺れ幅 0 / 12 / 24 で比べる）
- [ ] 補正に気づいたか（気づかないのが理想）。補正の強さ 0 / 1 / 2 で比べる
- [ ] タッチのとき、指より上に出る照準は自然だったか

## 射撃タイプ（コルク銃 / パチンコ）について

B・C それぞれで、コルク銃とパチンコを比べてください。

| 観点 | コルク銃 | パチンコ |
| --- | --- | --- |
| 狙うのが楽しかったか | | |
| 「当たるかな」とドキドキしたか | | |
| 当てられなくて算数を考える余裕がなくなっていないか | | |
| 1発にかかる時間（テンポ）はよいか | | |

- [ ] パチンコの操作（どこでも押して引っ張る）を説明なしで理解できたか
- [ ] 弾の速さ（600 / 800 / 1200）で、動く的の先読みが楽しいか難しすぎるか
- [ ] ガイドの長さ（0 / 260 / 600）で、狙いやすさと緊張感はどう変わるか
- [ ] 壁ではね返る弾を狙って使ったか
- [ ] パチンコでは的が1段になる。2段のコルク銃と比べて、射的らしさは変わったか

## C について

- [ ] 「小さい的（大きい数・×2）を狙うか、大きい的で確実にいくか」で迷ったか
- [ ] 安全な道と近道、どちらを選んだか（ログの `clear.key` でも確認できる）
- [ ] 動く的は速すぎ／遅すぎなかったか（移動の速さ 0.5 / 1 / 1.5 で比べる）
- [ ] 当たったときの手応え（揺れ・倒れる間・音）は気持ちよかったか、テンポが悪くなっていないか
- [ ] 景品がもらえることが、やる気につながったか

## 式の表示について

- [ ] 「いまの式」表示のオン／オフで、算数っぽさや考えやすさは変わったか

## 遊んだあとに（ログで見るとよいこと）

- 問題ごとの `clear` と `out_of_shots` の数（クリア率）
- `clear.isNew` が false のクリア（同じ解き方をくり返していないか）
- `shot.hitTargetId` が null の割合（B と C の外れ率）。`shooter` 別（gun / sling）に比べる
- パチンコの `shot.launch.bounces` が 1 以上の命中（壁を使った狙い）、`shot.assist` が 1 より大きいときの命中率
- `value_change.reachable` が false になってから、何発撃ったか・「さいしょから」を押したか
- `problem_start.reason` が `another_way`（べつの解き方をさがす）の回数
