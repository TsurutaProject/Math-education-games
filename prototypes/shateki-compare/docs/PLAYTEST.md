# 遊び比べチェックシート

#53 から、ステージは単元ごとの区切りになり、1つのステージの中で A〜E が問題ごとに変わります（ステージ 1：A・A・C・D・C・E、2：A・C・D・C・E、3：B・C・D・C・E）。コースの順に遊ぶと、遊び方の順番は全員同じになります。
遊び方を見比べたいときは、ステージ 1 を最初から順に遊んでもらい、下の表は遊び方ごとに書きます。

## 遊ぶ前に

- [ ] 設定パネルで「ログを消去」した（または前のログをダウンロードした）
- [ ] 効果音をオン、音量を確認した
- [ ] 遊ぶ順番を記録した：＿＿＿＿＿＿

## はじめの手引きについて（#15）

- [ ] マップで、光っている 1-1 を撃てたか。ほかの問題を撃って戸惑っていなかったか
- [ ] 吹き出しの言葉を読んでいたか（読まずに「わかった」を押していないか）。ひらがなの量はちょうどよいか
- [ ] 光っている的を押して数が変わったのを見て、「当てると数が変わる」「めあてと同じにする」が伝わったか
- [ ] 手引きのあと、自分で的を選んで 40 にできたか
- [ ] 「とばす」を押した子はいたか。どの手順で押したか（ログの `tutorial` の `from`）
- [ ] パチンコ・輪投げの指のアニメを見て、1発目で引っ張って撃てたか（説明なしのときと比べて）

## マップとステージの流れについて（#53）

- [ ] マップを見て、いまどこまで進んでいるか（挑戦済み・クリア・★ クリア）がわかったか
- [ ] はじめの説明の問題（A・B）を飛ばさずに遊んだか。飛ばした子は、メインの問題で迷っていなかったか（ログの `map_select.skippedMapNos`）
- [ ] はじめの問題で、そのステージの単元（たしざん・ひきざん・かけざん・わりざん）が伝わったか
- [ ] 1つのステージ（5〜6 問）が長すぎ・短すぎなかったか
- [ ] C・D・C・E と遊び方が変わることで、続けて遊びたくなったか。毎回の遊び方の説明で戸惑っていなかったか
- [ ] ステージ 3 の ÷ は、割り切れる数だけでも「わり算らしさ」が伝わったか
- [ ] マップの左右の矢印・スクロールで、ほかのステージに動けたか

## D について

- [ ] レーンの速さ（80 / 120 / 180）で、札を読んで「あと〇」を考える時間はあったか。速すぎて算数を考える余裕がなくなっていないか
- [ ] 「使いたい札が流れてくるのを待って撃つ」は楽しかったか、もどかしかったか
- [ ] 画面に出る的の数（3 / 4 / 6）で、選びやすさと忙しさはどう変わるか
- [ ] C（左右に揺れる的）と比べて、射的らしさ・やってみたい気持ちはどうか
- [ ] 救済のオン／オフで、待ち時間のイライラは変わったか（気づかないのが理想）
- [ ] 当てた的が倒れて消えたあと、レーンにできた空きが気にならなかったか
- [ ] コルク銃とパチンコ、どちらが D に合っていたか
- [ ] 左の看板「ながれる ふだ」を見ていたか。看板があると、流れてくる札を待つあいだに「どれとどれで届くか」を考えていたか（設定でオン／オフを比べる。#62）
- [ ] 3-3 で、はじめは流れてこない × ÷ を、看板を見て待ったり、先に + を当ててから狙ったりしていたか

## E について

- [ ] 「当てたら別の場所に起き上がる」は、説明なしでわかったか。起き上がった的に気づいたか
- [ ] 起き上がるまでの秒数（0.5 / 1 / 2）で、テンポと考える時間はどうか
- [ ] 立っている的の数（4 / 6 / 7）で、選びやすさと忙しさはどう変わるか

## 式の表示について

- [ ] 「いまの式」表示のオン／オフで、算数っぽさや考えやすさは変わったか
- [ ] ×2 が直前の数にだけかかる計算（+5 → +10 → ×2 で 25）は、当てる前の予想どおりだったか。式を見て納得できたか

## 遊んだあとに（ログで見るとよいこと）

- 問題ごとの `clear` と `out_of_shots` の数（クリア率）
- `clear.isNew` が false のクリア（同じ解き方をくり返していないか）
- `shot.hitTargetId` が null の割合（B と C の外れ率）。`shooter` 別（gun / sling）に比べる
- パチンコの `shot.launch.bounces` が 1 以上の命中（壁を使った狙い）、`shot.assist` が 1 より大きいときの命中率
- `value_change.reachable` が false になってから、何発撃ったか・「さいしょから」を押したか
- `problem_start.reason` が `another_way`（べつの解き方をさがす）の回数
- `attempts` を `unit`（単元）ごとにまとめたクリア率・時間（どの単元でつまずいたか）
- `map_select` の `skippedMapNos`（説明の問題を飛ばしたか）・`mapMs`（マップで迷った時間）・`misses`
- `attempts.firstPressMs`（問題を始めてから最初に押すまで）を `role`（intro / main）ごとに比べる
