# ケーキ切り分け分数学習ゲーム

小学生向けに、ホールケーキを切ってピースを最大3個まで組み合わせ、注文された分数ぴったりに販売するReact + TypeScript製のMVPです。
販売で売上をためると、新しいケーキを解放できます。

## 起動方法

Node.js 22.12 以上（推奨: Node.js 24）を使用してください。
リポジトリのルートから `cd games/cake` で移動して実行します。

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

## 学べること

- `1/2 = 1/4 + 1/4`
- `3/4 = 1/2 + 1/4`
- `3/4 = 1/4 + 1/4 + 1/4`
- `1/2 = 1/6 + 1/12 + 1/4`

式の暗記ではなく、切る・選ぶ・組み合わせる操作を通じて、分数の量感を視覚的に確かめられます。

## ゲーム要素

- 売上とコンボで販売の達成感を出します。
- 売上を使ってチョコレートケーキを解放できます。
- 解放済みのケーキは販売する種類として選択できます。
- チョコレートケーキ解放後は、チョコレートケーキを注文するお客さんも来るようになります。
- ケーキごとに色やトッピング配置が変わり、切り方の考えどころが変わります。
- 販売に成功すると次のお客さんが来て、売るほど少しずつ難しい注文が混ざります。
- 指定された作り方どおりにピースを組み合わせると、作り方ボーナスが入ります。
- 量は合っているけれど作り方ボーナスを逃す場合は、販売前に確認が出ます。
- トッピングを切らずに提供できると「なおよし」として追加評価されます。
- コンボ、累計売上、販売人数などのミッション達成でトロフィーが解放されます。
- 未解放と解放済みのトロフィーは、お客さんの列の下に表示されます。

## 主な構成

- `src/components`: 画面部品
- `src/data`: 注文とステージデータ
- `src/types`: ゲーム用型定義
- `src/utils/fraction.ts`: 分数計算
- `src/utils/cakeGeometry.ts`: SVG用のケーキ形状計算

## 画面の操作

- まな板の「切る」「移す」でナイフとトングを切り替えます。
- トレーに移したピースを押すと、そのピースをまな板に戻せます。
- 「切り直す」はトレーと切り方をリセットします。
- トレー下の「提供する」で注文の判定を行います（空のトレーでは押せません）。
- 注文の「ヒント・最高評価の条件」を開くと組み合わせの例や必要なピース数を確認できます。
- クリア条件の横に販売人数、トレー下に売上・コンボ・トロフィーを表示します。
- 追加素材の元画像は `src/data/cake-assets/`、表示用の軽量版は `src/data/ui/` にあります。

## ステージ構成と開発者モード

| ステージ | 内容 | 販売人数 |
| --- | --- | --- |
| 1 | 基本の分け方 | 3人 |
| 2 | 3つと6つの分け方 | 4人 |
| 3 | トッピングの注文 | 5人 |
| 4 | 組み合わせ注文（チョコレートケーキを解放） | 5人 |
| 5 | ピース数チャレンジ | 5人 |
| 6 | ランダムピース数チャレンジ | 6人 |
| 7 | 2つのケーキを合わせよう | 5人 |
| 8 | ケーキ屋さんマスター | 10人 |

ステージ4では従来どおり、販売人数に加えてチョコレートケーキを購入して解放するとクリアです。
ステージ7では両種類のケーキを同じトレーにのせ、種類ごとの分量を判定します。
ステージ8は基本・組合せ・指定ピース数・ランダムピース数・トッピング・両ケーキの6種類を、一巡するまで重複なく出題する総合ステージです。

進捗はステージIDで引き継ぎ、解放済みの内容へ引き続き入れます。旧「ケーキ屋さんマスター」は新しい総合ステージとは別扱いとし、新総合ステージを自動でクリア済みにはしません。

ゲームURLの末尾に `/admin` を付けると、全8ステージ・両ケーキを解放した開発者モードになります。

- 開発サーバーの例：`http://localhost:5187/admin`
- `/cake/` に配置した本番ビルドの例：`http://localhost:8765/cake/admin/`
- `/admin`を外すと通常モードです。開発者モードの進捗はメモリ内だけに保持し、再読み込みで初期化されます。通常の進捗・ログは変更しません。
- 開発者モードは研究ログを記録しません。ログ取得・キャッシュクリアの設定画面も無効です。初回チュートリアルは自動表示せず、メニューから手動で確認できます。
- 静的ホスティング向けに`admin/index.html`も生成します。サブディレクトリへ配置する場合は`npm run build -- --base=./`でビルドしてください。

追加ステージの販売判定、切替・返却・チュートリアル復帰の確認：`npm run test:stages`。

### トッピングの出題

ステージ3は基本的な分量の6種類から、一巡するまで重複せずに出題します。5/12・7/12などの分量や、離れたピースを合わせる難しいトッピング注文はステージ8で出題します。

トッピング配置は注文ごとにランダム生成します。最大3ピース・30度刻みのガイドで、トッピングを切らずに達成できる配置を生成します。ヒントの開閉・切り直し・途中のチュートリアルでは配置を変えません。
