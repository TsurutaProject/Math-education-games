# games/

本番のゲームを置くフォルダです。1ゲーム = 1フォルダにします。

```
games/
├─ shateki/   射的（prototypes/shateki-compare の遊び比べの結果を見てから作る）
└─ cake/      ケーキゲーム
```

## ゲームを追加するとき

1. `games/<ゲーム名>/` を作る（フォルダ名は半角英小文字とハイフン。例：`cake`）
2. そのフォルダの中だけで動くようにする（`package.json` もフォルダの中に置く）
3. フォルダの中に `README.md` を置き、次のことを書く
   - どんなゲームか（算数のどこを扱うか）
   - 起動方法（例：`npm install` → `npm run dev`）
   - テストの実行方法
4. 自動テストを動かしたい場合は、`.github/workflows/ci.yml` にそのフォルダを追加する
5. ブランチを切って Pull Request を出す

技術（React / Vite など）はゲームごとに決めてかまいません。
ただし、あとでプラットフォームにまとめるときに楽なので、ブラウザだけで動く（バックエンドなし）形にそろえておくのがおすすめです。
